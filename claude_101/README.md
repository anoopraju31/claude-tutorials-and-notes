# Claude 101: Course Notes

**Course:** Claude 101, Anthropic Academy (free, self-paced, certificate of completion)
**Goal:** Learn to use Claude for everyday work, understand its core features, and know where to go next.
**Structure:** 6 sections, about 13 lessons, roughly 2.5 hours.

> Note: Section and lesson titles come from the official curriculum. The detail under each is a study summary based on how those Claude features work, not a transcript of the lessons.

---

## 1. Meet Claude

### What is Claude?

- Claude is an AI assistant made by Anthropic. It is a thinking partner, not just a chatbot.
- It handles writing, editing, research, analysis, coding, brainstorming, and learning.
- Available on web, desktop, and mobile, plus developer products (API, Claude Code).
- Anthropic's design focus is helpful, honest, and safe behaviour.
- Claude can be wrong. Verify important facts, numbers, and citations.

### Your first conversation

- Just start typing. You can talk to Claude in plain language.
- Attach files (PDFs, docs, images, spreadsheets) for Claude to read and work from.
- Use it as a back-and-forth: ask, review, refine.
- Start new chats for new topics to keep context clean.

### Getting better results

- **Give context:** who you are, who the audience is, what the output is for.
- **Be specific:** state the task, format, length, and tone.
- **Show examples:** a sample of what good looks like beats a description.
- **Give Claude the material:** paste or attach the source, don't rely on memory.
- **Iterate:** treat the first answer as a draft. Say what to change ("shorter", "more formal", "cut the second point").
- **Ask Claude to ask you:** "Ask me clarifying questions before you start."
- **Troubleshooting:** if the output is off, add missing context, narrow the task, or restate the goal. Don't just repeat the same prompt.
- **Mind the 4Ds of AI fluency:** Delegation (what to hand off), Description (how you prompt), Discernment (evaluating output), Diligence (responsible use).

## 2. Working on Your Desktop

- The desktop app lets Claude work with you in a more integrated way than a browser tab.
- Faster access, and it can connect to local files and tools where your plan allows.
- Pick the right mode or model for the job: lighter models for quick tasks, more capable ones for complex reasoning.

---

## 3. Organizing Your Work and Knowledge

### Projects

- A project is a workspace that groups related chats with shared context.
- Add **project knowledge** (documents, notes, data) so Claude has it in every chat.
- Add **custom instructions** (role, tone, rules) so you don't repeat yourself.
- Good for ongoing work: a client, a product, a research topic, a course.

### Artifacts

- Artifacts are standalone outputs that appear next to the chat: documents, code, web pages, diagrams, interactive tools.
- You can edit, iterate, version, and share them.
- Use them for anything you'll keep, reuse, or hand to someone else.

### Skills

- Skills are packaged instructions (and sometimes scripts) that teach Claude how to do a task your way.
- Examples: a house writing style, a report template, a file-format workflow.
- Claude loads a skill when it's relevant, so you get consistent results without re-prompting.

## 4. Expanding Claude's Reach

### Connecting your tools

- Connectors link Claude to apps like email, calendar, docs, chat, and project trackers.
- Claude can then read from and act in those tools instead of you copy-pasting.
- Review permissions and be deliberate about what you connect.

### Enterprise search

- Lets Claude search across a company's connected knowledge sources to answer questions with internal context.
- Results depend on what the organization connects and what you have access to.

### Research for deep dives

- Research mode runs multi-step searches across the web (and connected sources), then synthesizes a report with citations.
- Best for broad, multi-source questions: market scans, comparisons, literature overviews.
- Takes longer than a normal chat, so give it a clear, well-scoped question.
- Check the cited sources for anything high-stakes.

## 5. Putting It All Together

### Claude in action: use cases by role

- Examples span roles such as marketing, sales, operations, finance, HR, product, engineering, and education.
- Common patterns: draft and edit content, summarize long documents, analyze data, prepare meetings, plan projects, and automate repeat tasks.

### Other ways to work with Claude

- **Claude Code:** agentic coding from the terminal and other surfaces.
- **Claude Cowork / agentic tasks:** multi-step work on files and tasks with less hand-holding.
- **Claude API and Platform:** build Claude into your own apps.
- **Mobile apps and integrations** for working on the go and inside tools you already use.

## Quick Cheat Sheet

| Need                                       | Use          |
| ------------------------------------------ | ------------ |
| One-off question or draft                  | Regular chat |
| Ongoing work with shared context           | Project      |
| A document, page, or tool to keep and edit | Artifact     |
| Repeatable, consistent method              | Skill        |
| Work with your apps and data               | Connectors   |
| Broad, cited, multi-source investigation   | Research     |

**Prompt checklist:** context → task → format/length/tone → examples → source material → iterate.

**Golden rules:** be specific, give context, iterate, verify what matters.
